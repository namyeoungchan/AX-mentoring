# 과제 제출 원장과 알림

1차 정책은 기존 `(assignment_id,user_id)` 중복 제약을 유지합니다. 개인마다 한 번 제출하고 팀에 한 건 이상 있으면 팀은 완료로 집계합니다. 여러 팀원의 원본 제출은 보존하며 대표본으로 합치거나 덮어쓰지 않습니다. 대표 제출·재제출·수정 이력 정책 변경은 별도 마이그레이션으로 진행합니다.

## 운영자 화면

관리자 **과제 관리 → 과제 제출 대상·알림**에서 과제를 펼쳐 제출 완료/미제출 명단을 확인합니다. 봇에서 만든 과제가 아직 과정에 연결되지 않았다면 대상 과정을 선택해 **과제 대상 과정 연결**을 누릅니다. 잘못된 일괄 알림을 막기 위해 연결된 과정은 이 화면에서 바꾸지 않습니다. 팀 대상은 활성 수강생이 있는 팀, 개인 대상은 활성 수강생입니다.

신규 제출은 같은 DB 트랜잭션에서 알림 대기를 생성합니다. Discord 전송은 봇의 별도 outbox가 수행하므로 채널 권한·Bot/Discord 장애가 제출 저장을 실패시키지 않습니다. 운영자 알림은 관리되는 비공개 과제 대시보드에 과제명·제출자·팀·제출 시각만 게시합니다. 본문과 제출 링크는 기존 권한이 있는 Web 제출 상세에서 확인합니다. 이전 봇 DB 전체 이관은 과거 제출 알림을 새로 만들지 않습니다.

팀 식별자는 확인 가능한 제출 시점에 보존합니다. 이후 팀 이름 변경으로 완료 기록이 사라지지 않습니다. 기존 제출의 팀을 식별할 수 없으면 경고 수를 표시하므로 원본 제출과 대조하세요. Discord 메시지 수를 제출 건수로 간주하지 않습니다.

## D-1 안내

Web이 매분 한국시간 D-1 오전 9시 이후의 미제출 대상을 계산합니다. 팀 과제는 해당 비공개 팀 채널, 개인 과제는 워크스페이스 Discord 인증을 마친 수강생의 DM으로 보냅니다. 개인 DM 차단은 실패로 기록됩니다. 멘션은 사용하지 않습니다. 과제·마감일·대상별 한 번만 생성하며, D-1 당일 재시작하면 놓친 생성을 이어서 처리합니다.

전송 대기 중 제출 완료·과제 마감·기한 변경·대상 제외를 발견하면 취소합니다. 이미 발송 중인 메시지는 되돌릴 수 없으므로 안내문은 Web 제출 원장 확인을 요청합니다. D-1이 지난 미발송 안내는 늦게 보내지 않고 취소합니다. 과제의 저장된 마감 날짜는 한국시간 운영 날짜로 해석합니다.

## 장애와 수동 안내

- **대기 + 채널 미설정**: Discord 서버 구성에서 비공개 과제 대시보드를 적용합니다. 대기는 사라지지 않습니다.
- **대상 확인 필요**: 수강생 Discord 인증, 팀 채널·역할 구성을 확인합니다. Web 명단과 과제 제출은 유지됩니다.
- **실패**: 권한·채널·DM 설정을 고친 뒤 **알림 재시도**를 누릅니다.
- **결과 확인 필요**: **기존 메시지 확인**으로 조회합니다. 조회 증거가 없으면 자동 재전송하지 않습니다.
- **수동 안내**: 먼저 해당 행의 **자동 알림 중지**로 발송 대기를 보류한 뒤 **안내문 복사**를 사용합니다. 미제출 명단을 다시 확인하고 담당자가 팀 채널/개별 연락으로 안내합니다. 언제 누구에게 안내했는지는 현장 기록에 남깁니다. 발송 중에는 중지할 수 없습니다.

메시지 ID·오류·시도 횟수는 Web에서 확인하며 자세한 공통 전송 정책은 [NOTICE-DELIVERY.md](./NOTICE-DELIVERY.md)를 참고합니다. Web 저장소로 전환한 봇은 기존 비영속 D-1 루프를 사용하지 않습니다. 로컬 DB만 쓰는 기존 설치는 기존 동작을 유지합니다.

자동 테스트는 실제 SQLite 및 storage API의 제출·알림 원자성, 재시작 중복 방지, D-1 팀/개인 대상, 취소, 비공개 전송·DM 경로, timeout·권한·rate limit을 검증합니다. 실제 Discord 서버 발송과 현장 담당자 리허설은 별도로 확인해야 합니다.

## 과제 배포 알림

웹에서 과제를 등록할 때 팀/개인 유형을 선택합니다. 등록 후 과제별 상세에서 과정·대상·마감일을 확인하고 **과제 배포**를 누릅니다. 팀 과제는 과정 내 정상 수강생이 있는 각 팀의 비공개 팀 채팅, 개인 과제는 대상 수강생의 Discord DM에 안내합니다. 기존 과제는 자동 배포되지 않습니다.

배포 요청은 현재 명단을 고정해 과제·대상별 한 번만 저장하며, 새로고침/중복 클릭에도 재발송하지 않습니다. 명단 변경은 배포 전 다시 확인해야 합니다. 배포 후 합류한 수강생은 기존 배포에 자동 추가되지 않습니다. 배포 시각은 발송 완료를 의미하지 않으며 화면에서 개별 대기·완료·실패 상태를 확인합니다.

팀 채널/역할이 아직 없거나 개인 Discord 인증이 누락되면 대기 사유가 표시됩니다. 연동을 마치면 자동으로 대상 주소를 확인합니다. DM 차단/권한 오류는 실패로 표시하고 운영자가 재시도합니다. 응답을 잃은 경우 기존 메시지를 확인하며 무조건 새 메시지를 보내지 않습니다. 과제가 마감되거나 대상 소속·Discord 계정·서버가 변경되면 대기 중인 배포를 취소합니다. 배포 후 기존 과제 유형을 바꿀 수 없습니다.
