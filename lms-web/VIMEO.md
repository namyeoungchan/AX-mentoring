# 강의 영상 운영

멘토·관리자의 **강의 영상 → 영상 업로드**에서 과정, 제목, 설명, 파일을 선택합니다. 파일은 브라우저에서 Vimeo로 직접 전송됩니다. 웹 서버와 PostgreSQL에는 영상 파일이 아닌 과정 연결과 게시 상태만 저장합니다.

- 기본 파일 제한: 5 GiB. MP4, MOV, M4V, WEBM, AVI, MKV.
- 전송 중 이 화면을 유지하세요. 일시 중지·네트워크 오류 후에는 **이어 올리기**에서 동일한 원본 파일을 선택합니다. 파일 이름, 크기, 수정 시간이 일치해야 합니다. 페이지를 다시 열어도 업로드 URL이 유효하면 이어 올릴 수 있습니다.
- 변환 상태는 화면을 보고 있는 동안 15초마다 확인합니다. 새로 열린 화면에서 **상태 확인**으로 수동 확인할 수도 있습니다.
- **영상 설정 → 수강생에게 게시**를 선택해야 재생할 수 있습니다. 게시 해제는 Vimeo도 비공개로 전환합니다.
- 멘토는 담당 과정에 업로드하고 자신이 등록한 영상을 수정합니다. 관리자는 전체 과정을 관리합니다. 영상 공개 범위는 선택한 과정 전체입니다.
- 수강생은 기존 학습 화면과 동일하게 워크스페이스 멤버십, 해당 서버의 Discord 인증, 정상/수료 상태인 과정에 한해 접근합니다. 비활성·중도탈락·타 과정의 재생 API 접근을 차단합니다.

## 환경 설정

로컬은 `lms-web/.env`, 운영은 Render **ax-learningops-web → Environment**에 설정합니다. Discord 봇에는 필요하지 않습니다. 토큰은 Git과 `VITE_*`에 넣지 않습니다.

```dotenv
VIMEO_ACCESS_TOKEN=인증된_운영계정_토큰
# 선택: 비우면 ALLOWED_ORIGINS 및 RENDER_EXTERNAL_URL에서 호스트명을 가져옵니다.
VIMEO_EMBED_DOMAINS=ax-learningops-web.onrender.com,namyeoungchan.github.io
VIMEO_MAX_UPLOAD_BYTES=5368709120
```

토큰에는 `private`, `upload`, `edit` 권한이 필요합니다. API 앱의 업로드 권한도 활성화되어야 합니다. Vimeo 계정 하나에 앱의 여러 멘토가 올리는 구조이며, 수강생에게 Vimeo 계정이나 유료 좌석을 발급하지 않습니다.

영상 생성 시 Vimeo를 비공개(`nobody`)로 만들고 임베드 허용 도메인(`whitelist`)을 설정합니다. 게시할 때 `disable`(Embed only)로 전환합니다. 기존 프리셋에서 상속된 허용 도메인은 제거하며 일반 다운로드를 비활성화합니다. 도메인 설정을 바꾼 기존 영상은 게시를 해제한 뒤 다시 게시해야 새 도메인이 적용됩니다. 도메인 제한은 DRM이나 화면 녹화 방지를 제공하지 않습니다.

Vimeo 처리 중 실패하면 수강생에게 자동 게시하지 않습니다. 영상 생성 응답을 잃은 요청은 같은 요청 번호로 재생성하지 않습니다. Vimeo 관리 화면에서 생성 여부를 확인한 후 필요하면 다시 업로드합니다. 전송을 중단한 초안과 실패한 영상은 Vimeo 저장 공간을 사용할 수 있으며, 불필요한 원본은 Vimeo 관리 화면에서 정리합니다.

DB 백업은 영상 연결·게시 상태를 포함하지만 Vimeo 원본 파일은 포함하지 않습니다. DB 초기화는 Vimeo 영상을 삭제하지 않습니다.

## 요금 및 전송량

Starter의 지정 도메인 임베드를 사용합니다. 외부 수강생 80명은 유료 관리 좌석 80개에 해당하지 않습니다. 실제 청구액은 가입한 Starter의 결제 주기와 세금에 따릅니다. 공식 공개 페이지는 현재 좌석당 월 $12를 표시합니다.

월 전송량 2 TB(2,000 GB)가 기준입니다. 대략적인 전송량은 `수강생 수 × 시청 시간 × 평균 Mbps × 0.45 GB`입니다. 80명이 각각 월 20시간 시청하면 평균 2 Mbps에서 약 1,440 GB, 4 Mbps에서 약 2,880 GB입니다. 자동 화질과 반복 시청으로 달라지므로 Vimeo 사용량을 확인합니다. 초과 시 고정된 GB당 요금으로 가정하지 말고 Vimeo의 안내에 따라 사용량 또는 계약을 조정합니다.
