# 멘토·수강생 화면 일관성 점검

2026-09-18. 워크스페이스 관리자 화면의 레이아웃과 스타일을 기준으로 적용했다.

| 점검 항목 | 적용 내용 |
| --- | --- |
| 화면 구조 | 멘토 가로 탭과 수강생 단일 화면을 관리자와 같은 좌측 메뉴·상단 경로·페이지 제목·카드 구성으로 변경 |
| 공통 동작 | 워크스페이스 선택, 새로고침, 비밀번호 변경, 로그아웃, 역할별 PDF 도움말 |
| 멘토 메뉴 | 수업 현황, 출결 관리, 팀 배정, 성적 관리, 가입 승인, 멘토 온보딩 |
| 수강생 메뉴 | 나의 학습, 나의 출결, 나의 성적, 과제, 워크스페이스 참여 |
| 이동과 복귀 | URL 해시로 현재 메뉴 유지, 새로고침·뒤로가기 지원, 허용되지 않은 경로는 역할 기본 화면으로 이동 |
| 모바일·키보드 | 메뉴 열기·접기, Escape, 포커스 복귀, 열린 메뉴 안의 Tab 이동, 닫힌 메뉴와 배경의 접근 차단, 본문 바로가기 |
| 기록이 없는 화면 | 출결·성적·과제별 빈 상태와 다음 행동 안내, 코드 출석과 회차 마감 설명 |
| 권한 | 기존 멘토 담당 범위와 수강생 본인 기록 API 유지, 관리자 메뉴 및 API 접근 불가 |
| 초기 로딩 | 역할 화면을 필요할 때 불러와 공통 시작 번들 크기 증가 방지 |

`tests/role-workspaces.spec.ts`는 실제 임시 DB의 멘토·발급 학생 계정으로 전체 메뉴, 새로고침과 뒤로가기, 1440/390/360px 레이아웃, 키보드 포커스, PDF 링크, 관리자 API 차단을 검증한다. 기존 가입 승인·온보딩·학생 첫 로그인 테스트도 새 메뉴 경로를 사용한다. 스크린샷은 `test-results/`에 생성하며 역할별 PDF의 A4 크기·페이지 넘침·폰트·링크도 확인한다.

실제 운영 Discord에서 학생과 멘토가 수행하는 현장 리허설은 자동 브라우저/API 검증과 별도로 남아 있다.
