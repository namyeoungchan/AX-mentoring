# 엑셀 수강생 등록

관리자의 **학생 계정 발급** 또는 **Discord 빠른 설정 → 운영할 조 설정**에서 엑셀 양식을 내려받습니다. 기존 참여자통합관리 파일도 그대로 사용할 수 있습니다.

1. `명단` 시트에 학생ID, 상태, 팀, 성명을 입력합니다. 상태가 `참여`인 행만 처리하며 `제외`는 건너뜁니다. 학교·학과·연락처·이메일도 저장합니다. 설문·출결 열은 이번 등록에 반영하지 않습니다.
2. 파일을 선택하면 등록 가능, 기존 계정, 실패, 제외 내역이 표시됩니다. 이 단계에서는 저장하지 않습니다. 실패 원인을 확인한 후 정상 행만 **적용**하거나 **취소**합니다.
3. Discord 빠른 설정에서는 명단의 팀 이름으로 조를 먼저 준비할 수 있습니다. 서버 연결·봇 초대 후 조별 역할과 대화·음성 채널이 생성됩니다. 기존 조는 삭제하지 않습니다.
4. 서버 연결 후 학생 계정 발급에서 같은 파일을 등록합니다. 학생ID는 영문 소문자로 저장됩니다. 초기 비밀번호는 `bdaxuser1!`이며 첫 로그인에서 변경해야 합니다. 파일을 다시 올려도 기존 비밀번호는 바뀌지 않습니다.
5. 처리 후 성공·실패 결과를 확인합니다. 다른 계정과 아이디가 충돌하거나 기존 이름·과정·조가 다르면 해당 행은 덮어쓰지 않습니다. 부분 실패는 해당 행을 수정한 뒤 다시 등록합니다.

수강생 목록에서 개별 계정을 추가하고 이름·학교·학과·연락처·이메일을 수정하거나 조를 변경할 수 있습니다. **수강생 삭제**는 확인 후 현재 워크스페이스 소속·가입 정보·Discord 인증을 제거하고 기존 학습 명단을 비활성화합니다. 출결·과제 이력과 로그인 계정, 다른 워크스페이스 소속은 보존합니다. 전체 로그인 계정의 영구 삭제는 총관리자의 전체 계정 관리에서 수행합니다.

파일은 `.xlsx`, 2MB 이하, 최대 500행이며 한 번에 참여자 100명까지 처리합니다. 동일 학생ID가 여러 행에 있으면 해당 행 모두 실패로 표시합니다. 원본 개인정보 파일은 저장소에 포함하지 않습니다.

양식 생성: `python scripts/create-roster-template.py`. 배포 파일은 `public/templates/student-roster-template.xlsx`입니다.
