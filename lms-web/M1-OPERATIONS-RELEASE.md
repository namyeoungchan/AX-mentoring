# 마일스톤 1 운영 기능 추가 배포

2026-09-17 `feature` → `develop` → `release/m1-operations-update` → `main` 후 `develop` 역반영으로 배포한다. 최종 커밋, 검증과 배포 결과는 GitHub Release `m1-operations-2026-09-17`에 기록한다.

## 변경 사항

- #11 / PR #36: 강사 출결 명단 검색, 팀·상태 필터, 선택 일괄 지정, 미처리 출석 처리, 저장된 집계의 Discord 비공개 운영 채널 공유. 강사별 담당 범위와 동시 변경·마감 사유 검사를 유지한다.
- #35 / PR #38: 총관리자의 전체 계정 초기 비밀번호 재발급 및 삭제. 새 임시 비밀번호는 한 번 표시하고 기존 세션을 해제한다. 학습 기록은 보존하고 마지막 총관리자 삭제는 차단한다.
- #37 / PR #39: 팀/개인 과제 생성 및 명단 확인 후 배포. 팀 비공개 채팅 또는 인증된 수강생 DM으로 과제명·마감일을 전송한다. 중복 요청을 차단하고 발송 대기·실패·결과 확인 상태와 재시도를 제공한다.

## 검증과 배포

서버 111개, Python 86개, 통합 브라우저 검증 및 빌드·린트 결과를 최종 CI에서 확인한다. 실제 운영 계정 초기화·삭제나 수강생 테스트 메시지 발송은 검증에 포함하지 않는다.

운영 대상과 영속 디스크는 [M1-RELEASE.md](./M1-RELEASE.md)와 동일하다. 두 활성 서비스의 자동 배포와 Pages를 잠시 제어하고 **이전 API와 호환되는 봇을 먼저 배포**한다. 봇 정상 연결 이후 같은 커밋의 Web/API를 배포하고 Pages를 갱신한다. 서비스 시작 전 백업, health, 데이터 건수, 공개 로그인 화면을 확인한 후 기존 자동 배포 설정을 복구한다.

Web은 엄격한 백업 검사를 유지한다. 기존 봇 DB의 외래 키 오류는 기존 명시적 보존 옵션과 #34를 유지하며 데이터를 삭제하거나 정리하지 않는다. 중지된 예전 Web과 중복 봇은 시작하지 않는다.

## 운영 흐름

- 출결: 명단에서 예외 처리 → 미처리 출석/선택 일괄 처리 → 저장 → 필요 시 Discord 출결 공유.
- 계정: 총관리자 로그인 → 전체 계정 관리 → 아이디 확인 후 초기 비밀번호 재설정 또는 삭제.
- 과제: 과제 만들기에서 유형 선택 → 상세의 대상·마감일 확인 → 과제 배포 → 알림별 발송 상태 확인. 개인 수강생은 Discord 인증과 DM 수신이 가능해야 한다.

실제 Discord 수신 확인과 현장 리허설, 문서 인수는 자동 검증과 구분한다. 기존 #15·#16의 현장 완료 조건은 계속 추적한다.
