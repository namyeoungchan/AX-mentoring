# 관리자 발급 학생 계정

워크스페이스 관리자는 **학생 계정 발급**에서 아이디, 선택 이름, 과정·조를 입력합니다. Discord 서버 연결과 조 구성을 먼저 완료해야 합니다. 초기 비밀번호는 발급 직후 한 번 표시되며 학생에게 개별 전달합니다.

학생은 직접 가입하지 않습니다. 발급된 아이디와 초기 비밀번호로 로그인한 뒤 본인 이름과 새 비밀번호를 입력합니다. 설정 전에는 학습 데이터, 가입 신청, Discord 인증에 접근할 수 없습니다. 설정 후 **워크스페이스 참여 현황**에서 Discord 서버에 참여하고 LMS 인증을 완료합니다. 자기소개까지 완료하면 팀 채널에서 수업에 참여할 수 있습니다.

초기 비밀번호를 분실하면 총관리자가 **전체 계정 관리**에서 재발급합니다. 워크스페이스 관리자는 다른 워크스페이스에 계정을 발급하거나 기존 계정을 덮어쓸 수 없습니다. 기존 학생의 로그인과 이미 발급된 가입 요청은 유지됩니다.

## 저장과 검증

- 계정·배정·감사 기록을 한 트랜잭션에 저장하며 초기 비밀번호는 해시로만 저장합니다.
- 첫 로그인 설정 완료 시 이전 세션을 모두 폐기하고 새 세션을 발급합니다.
- 기존 계정은 추가 열의 기본값 0으로 첫 로그인 설정 대상에서 제외됩니다.
- 운영 환경의 공개 학생 가입 API는 403을 반환합니다. 기존 가입 경로는 NODE_ENV=test와 ALLOW_LEGACY_STUDENT_REGISTRATION=true를 모두 지정한 회귀 테스트에서만 허용합니다.
- 관리자 권한, 중복 아이디, 다른 워크스페이스 접근, 설정 우회, 동시 설정, 권한 회수, 트랜잭션 롤백을 자동 검증합니다.
