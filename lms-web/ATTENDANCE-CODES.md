# Discord 코드 출석

## 멘토·관리자

1. 웹 **출결**에서 과정·날짜·차시를 선택합니다. 관리자 또는 메인 강사가 **회차 시작**을 누릅니다.
2. **Discord 코드 출석**에서 유효시간(기본 5분, 1·3·5·10분)을 선택하고 **출석 코드 발급**을 누릅니다.
3. 수업 현장에서 학생에게 6자리 코드를 안내합니다. 조 담당 멘토의 코드는 발급 당시 담당 조의 정상 수강생만 사용할 수 있습니다.
4. 학생 등록은 명단에 5초마다 반영됩니다. 수기 수정 중에는 자동 갱신을 멈추며 다른 출결 변경과 충돌하면 명단 새로고침 후 확인합니다.
5. **코드 종료**, 유효시간 만료 또는 **회차 마감**으로 등록을 종료합니다. 재발급하면 같은 발급자의 해당 회차 이전 코드는 종료됩니다. 다른 멘토가 발급한 코드는 별도로 유지됩니다.
6. 미처리·지각·결석 등은 기존 명단 출결 기능으로 확인·저장합니다. 전체 명단을 처리한 뒤 회차를 마감합니다. 마감 후 정정에는 사유가 필요하며 변경 전후 이력이 남습니다.

코드 원문은 발급 직후 화면에서만 확인할 수 있습니다. 화면을 새로 열어 코드를 잊었다면 재발급하세요. 다른 날짜·과정·차시를 선택했는지 발급 전 확인하세요.

## 학생

관리자가 발급한 LMS 학생 계정의 첫 로그인 설정과 해당 워크스페이스의 Discord 인증을 완료합니다. 수업 Discord 서버에서 `/출석 코드:123456`을 실행합니다. 확인 메시지는 본인에게만 보이며 날짜·차시·출결 상태를 안내합니다.

코드는 유효시간 동안 대상 학생들이 함께 사용합니다. 같은 학생의 같은 회차 기록은 한 번만 생성됩니다. 중복 입력이나 재발급 코드로 멘토가 정정한 출결을 덮어쓰지 않습니다. 잘못된 기록은 멘토에게 정정을 요청하세요. 처리 결과를 받지 못했을 때 같은 코드로 재시도할 수 있으며, 학생별 서버당 1분에 5회까지 요청할 수 있습니다.

## 연결 및 운영

- 기존 `LEARNINGOPS_AUTH_URL`(`/api/integrations/discord/verify`)과 `LEARNINGOPS_AUTH_TOKEN`을 그대로 사용합니다. 웹·봇의 인증 키가 일치해야 합니다. 새 환경변수는 없습니다.
- 봇 시작 시 기존 워크스페이스 명령어 동기화가 `/출석`을 등록합니다. 웹과 봇을 함께 업데이트하세요.
- 서버가 봇 인증, Discord 서버 연결, 워크스페이스별 학생 인증·권한, 정상 수강 상태, 회차 상태와 발급 멘토의 현재 권한을 확인합니다. 학생 ID를 입력받아 대리 지정하는 기능은 없습니다.
- DB에는 코드 해시와 발급 범위·만료 시각만 저장합니다. 발급 및 출석 기록은 감사 이력으로 남습니다. 백업 복구 시 기존 출석 코드를 만료시킵니다.
- 이번 기능은 출석 코드 방식입니다. 위치 정보를 수집하지 않으며, 현장 참석 자체를 증명하지는 않습니다. GPS 확인이 필요하면 학생 동의를 받는 별도 웹 흐름을 추가해야 합니다.

검증: `npm test`, `npm run lint`, `npm run build`, `npx playwright test tests/attendance-codes.spec.ts tests/attendance.spec.ts`, `python -m unittest discover -s tests`.
