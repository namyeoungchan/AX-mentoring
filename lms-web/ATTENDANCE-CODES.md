# 강의 시작·종료 코드 출석

입실·퇴실이 강의 출석입니다. 별도의 자유 입퇴실 버튼으로 출석하지 않습니다.

1. 출결 관리에서 과정·오늘 날짜·차시와 **강의 시작/종료 예정 시각**을 입력합니다. 한국시간이며 종료가 시작보다 늦어야 합니다. 같은 날짜의 주차별 일정이 있으면 입력란에 제안합니다.
2. 관리자·메인 강사가 **시작 코드 생성 · 강의 시작**을 누릅니다. 강의가 시작되고 실제 시작 시각을 기록합니다. 학생에게 6자리 코드를 안내합니다.
3. 학생은 Discord 시작하기 패널의 **입실 · 시작 코드** 또는 웹 **나의 출결 → 코드로 출석하기**에서 코드를 입력합니다. 입실 시각이 서버 기준으로 저장됩니다.
4. 수업이 끝나면 **종료 코드 생성 · 강의 종료**를 누릅니다. 실제 종료 시각을 기록하고 모든 기존 입실 코드를 폐기합니다. 학생은 **퇴실 · 종료 코드** 또는 웹에서 종료 코드를 입력합니다.
5. 두 기록이 있으면 출석이 완료됩니다. 기존 지각·결석·공결 등 멘토 정정은 유지합니다. 입실 없는 퇴실은 거절합니다. 누락·예외를 확인해 저장하고 **출결 확정**으로 최종 기록을 공개합니다.

예정 시간대와 실제 강의 시작·종료 시각, 학생 입퇴실 시각을 구분합니다. 시각은 한국시간으로 표시합니다. 지각·조퇴는 자동 판정하지 않습니다. 현재 명단 상태는 출석·지각·결석·공결이며, 조퇴 등 특이사항은 사유에 기록합니다.

코드 유효시간은 1·3·5·10분입니다. 재발급은 최초 강의 시작·종료 시각을 바꾸지 않습니다. 종료 코드 만료 후에도 재발급할 수 있지만 강의는 종료 상태를 유지합니다. 코드 폐기는 강의 종료를 대신하지 않습니다. 조 멘토는 시작된 강의에서 담당 조의 입실 코드만 생성합니다. 강의 종료와 최종 확정은 관리자·메인 강사가 처리합니다.

## API와 저장

- `POST /api/workspaces/:id/attendance/code`: `courseId,date,period,phase(in|out),minutes`. 최초 시작에는 `startTime,endTime` (HH:mm)이 필수입니다.
- `POST /api/workspaces/:id/me/attendance`: `{code}`. 서버가 코드 종류와 대상 회차를 결정합니다.
- Discord `/attendance/presence/mark`: 봇 인증과 `guildId,discordId,code,action(in|out)`. 다른 종류의 코드는 거절합니다. `/attendance/checkin` 슬래시 경로는 코드 종류를 자동 판별합니다.
- 기존 코드는 해시만 저장합니다. `attendanceCode` 레코드가 코드 종류를, `attendanceSession`이 예정 시간대와 실제 시작·종료를, `attendancePresence`가 학생 입퇴실을 보관합니다. 기존 백업에 포함되며 신규 환경 변수·테이블 마이그레이션은 없습니다.
- 코드 발급·강의 상태·감사 기록, 학생 입퇴실·출결·버전 변경은 각각 하나의 트랜잭션으로 처리합니다. 웹/Discord 동시 입력은 최초 시각만 유지합니다.
- 이전 방식으로 발급된 코드는 새 시작·종료 코드로 재발급합니다. 기존 출결·입퇴실 기록은 보존합니다. 과거 수기 회차 API는 명단 복구 호환용으로 남습니다.
