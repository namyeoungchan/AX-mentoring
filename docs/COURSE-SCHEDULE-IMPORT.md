# 과정 일정 엑셀 가져오기

관리자 → 학습과정 → 과정 관리 → **주차별 일정**에서 **일정 샘플 다운로드**를 선택한다.
샘플 URL은 `/templates/course-schedule-template.xlsx`이다.

1. `주차별 시간표` 시트를 작성한다. 주차·날짜·시간대·세션명 열은 필수다.
2. **일정 엑셀 선택**으로 파일을 연다. 파일은 브라우저에서 읽으며 최대 2MB, 1,000행, 수업 104개까지 지원한다.
3. 미리보기에서 수업, 제외 행, 오류를 확인한다. 오류가 있으면 파일을 수정해 다시 선택한다.
4. **확인 · 편집에 반영**하면 현재 편집 중인 일정이 교체되고 과정 운영 기간·주차도 가져온 일정에 맞춰진다.
5. **일정 저장**을 눌러 최종 저장한다. 저장 전 취소할 수 있고, 다른 관리자의 동시 수정은 덮어쓰지 않는다.

`OT`는 0주차다. 같은 주차에 여러 수업을 등록할 수 있다. 휴강·합계 행은 수업에서 제외한다.
날짜는 `YYYY-MM-DD`, `M/D`, Excel 날짜 셀을 지원한다. 연도가 없는 날짜는 제목의 연도를 우선 인식하며 미리보기에서 기준 연도를 수정할 수 있다. 연도를 넘기는 일정은 연도까지 입력한다.
시간대는 `19:00~22:00` 형식이며 한국시간이다. 요일 불일치, 역전된 시간, 같은 날짜의 중복·겹치는 수업은 오류로 표시한다.
주제·구분·세부 내용·강사·산출물은 일정 메모에 보관한다. 별도 멘토링 시트는 가져오지 않으며, 확정한 날짜·시간을 시간표 시트에 추가하면 된다.

일정 가져오기는 과정 일정만 변경한다. 강사 계정 배정과 출석 회차 시작은 기존 운영 화면에서 진행한다.
공개 샘플은 가상의 수업으로 구성했으며 `lms-web/scripts/create-schedule-template.py`로 다시 생성할 수 있다.

# 과제 삭제

웹의 **과제 목록 → 삭제**와 디스코드의 **과제 삭제**는 같은 저장 작업을 사용한다.
관리자 확인 후 과제, 제출 내역, 과정 연결, 게시 기록의 연결과 미발송 알림을 정리한다.
삭제 확인 중 과제나 제출 내용이 바뀌면 최신 내역을 다시 확인해야 한다. 웹 요청 재시도는 같은 요청 ID로 중복 처리하지 않는다.
이미 발송한 디스코드 메시지와 감사 이력은 보관한다. 발송 중인 메시지는 이미 디스코드에 전달됐을 수 있으며 삭제가 이를 회수하지 않는다.
