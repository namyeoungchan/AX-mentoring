# 수강생 삭제

워크스페이스 관리자 → 수강생 관리 → 해당 행의 **삭제**에서 확인창을 엽니다. 이름, 과정·조, 연결된 로그인 계정, 보관할 출결·성적 건수를 확인한 뒤 **수강생 삭제**를 누릅니다. 취소하면 변경되지 않습니다.

- 현재 워크스페이스 명단과 연결된 학생 소속·인증·신청을 제거합니다. 로그인 계정 자체와 다른 워크스페이스 소속은 유지합니다.
- 기존 출결·성적·과제 제출은 보관합니다. 과거 출석부에는 기록이 있는 삭제된 수강생을 표시하고, 새 회차 명단에서는 제외합니다.
- 직접 등록한 수강생도 삭제할 수 있습니다. 계정은 신청 ID 또는 인증된 Discord ID로만 연결하며 이름·이메일로 추정하지 않습니다.
- 관리자·멘토에 연결된 수강생은 삭제를 차단합니다. 확인 중 학생 정보나 계정 연결이 바뀌면 최신 내역을 다시 확인해야 합니다.
- 학생 계정 발급 화면의 기존 삭제 기능도 같은 방식으로 현재 명단에서 제외합니다.

`removedLearners`에 학습 이력 표시용 원본을 보관하고 감사 로그를 남깁니다. 보관된 ID로 수강생을 다시 저장하거나 신규 성적을 등록할 수 없습니다. 기존 성적 정정은 허용합니다. 백업에는 보관된 원본도 포함됩니다.
