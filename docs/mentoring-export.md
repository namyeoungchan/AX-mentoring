# 멘토링 실제 진행 기록과 엑셀 내보내기

## 실제 진행 기록 (예약 멘토링)

종료된 예약 멘토링에서 **멘토링 일정 → 해당 일정 → 멘토링 기록 → 실제 진행 기록**의
`기록하기`/`수정` 버튼으로 실제 진행일·시작·종료 시간과 진행 내용을 남긴다.
처음 열면 예약 시간과 DM 멘토 응답이 미리 채워진다.

| 역할 | 기록·수정 |
| --- | --- |
| 담당 멘토 | 해당 워크스페이스 Discord 인증을 마친 계정이 예약 멘토와 일치할 때만 |
| 워크스페이스 관리자 / 총관리자 | 모든 종료된 예약 |
| 학생 | API 403 |

- 예약 확정·완료 상태이고 슬롯 종료 시각이 지난 예약만 대상이다. 승인 대기·취소·재조율 중인 예약과 보관된 워크스페이스는 제외한다.
- 실제 시간은 같은 날 시작 < 종료이며 현재 시각 이전이어야 한다.
- 예약 슬롯 시간과 Discord DM 응답 원문은 변경하지 않는다. 기록은 `lms_records`의 `mentoringSessionRecord`(예약 ID 기준)에 저장하고 변경 전후를 `lms_audit`(`mentoring.session.record`)에 남긴다. 스키마 변경은 없다.
- revision으로 충돌을 감지한다. 다른 창에서 먼저 저장했다면 409로 차단한다.
- `PUT /api/workspaces/:workspaceId/mentoring/:bookingId/feedback/record` `{date,time,endTime,content,revision}`. 응답은 기존 피드백 조회와 같고 `record`, `canRecord`가 추가된다.

직접 입력한 멘토링 기록(`+` 버튼)은 기존처럼 목록의 `수정`으로 시간·내용을 고친다. 수정된 기록에는 수정 시각이 표시된다.

## 엑셀 내보내기 (관리자)

관리자 멘토링 일정 화면의 **엑셀 다운로드**에서 기간을 지정해 `.xlsx`를 내려받는다.
기본 기간은 이번 달 1일부터 오늘까지이며, 한 번에 최대 2년이다.

- **요약** 시트: 멘토별 예약 멘토링·직접 기록·총 건수, 총 진행 시간(분/시간), 참여 학생·팀 수, 내용 미작성 건수, 최근 진행일과 합계. 아래에 워크스페이스·기간·생성 시각을 적는다.
- **멘토별 시트**: 날짜, 시작, 종료, 진행 시간, 구분(예약 멘토링/직접 기록), 제목, 과정, 팀, 참여자, 멘토링 내용, 멘티 응답, 상태.
- 포함 대상: 종료된 예약 확정·완료 예약과 직접 입력한 기록. 실제 진행 기록이 있는 예약은 그 날짜·시간·내용을 쓰고, 없으면 슬롯 시간과 DM 멘토 응답(웹 수정본 우선)을 쓴다.
- 예약 멘토는 Discord ID(없으면 이름)로 웹 멘토 계정과 묶어 한 시트에 모은다. 시트 이름은 Excel 규칙(31자, 금지 문자 제거)에 맞추고, 겹치면 번호를 붙인다.
- `GET /api/workspaces/:workspaceId/mentoring/export?from=YYYY-MM-DD&to=YYYY-MM-DD`. 관리자만 가능하고 멘토·학생은 403이다. 파일은 서버에서 의존성 없이 생성한다(`lms-web/server/xlsx.mjs`).
