# Discord 인증 기록 관리

총관리자는 왼쪽 메뉴 **Discord 인증 관리**에서 모든 워크스페이스의 인증 기록을 조회할 수 있습니다. 일반 관리자·멘토·수강생은 이 API를 사용할 수 없습니다.

- Discord ID, 이름, LMS 아이디, 워크스페이스명, 서버 ID로 검색합니다.
- **고아·불일치 기록** 필터는 계정이 삭제되었거나 현재 Discord 연결과 일치하지 않는 인증 기록을 표시합니다. 진행 중인 정상 가입 인증은 별도로 표시합니다.
- **인증 내역 보기**에서 계정 연결, 서버 인증, 인증 코드 이력, 멘토 연결과 인증 시각을 확인합니다. 인증 코드·비밀번호·토큰은 목록에 반환하지 않습니다.
- **인증 연결 해제 / 인증 기록 삭제**를 선택하고 해당 Discord ID를 입력하면 전체 워크스페이스에 걸친 선택한 ID의 인증 데이터를 정리합니다. 화면을 연 뒤 인증 정보가 바뀌었다면 삭제하지 않고 새로고침을 요청합니다.

연결된 LMS 계정이 있으면 해당 계정의 Discord ID를 미연결 상태로 바꾸고 로그인 세션과 발급한 인증 코드를 폐기합니다. 로그인 계정 자체, 워크스페이스 소속, 출결·과제·멘토링 등 운영 이력은 유지됩니다. 삭제 후 사용할 LMS 계정으로 로그인해 새 코드를 발급하고 Discord에서 다시 인증합니다.

수강 등록 삭제는 로그인 계정 삭제와 다릅니다. 수강 등록만 지운 경우에는 기존 LMS 계정이 Discord ID를 계속 점유할 수 있습니다. 이 탭에서 실제 연결 계정을 확인하고 필요한 경우 연결을 해제할 수 있습니다. 실제 계정 삭제 시에도 Discord ID 기준의 잔여 인증·연결·동기화 기록을 함께 정리합니다.

정리 작업은 DB 트랜잭션으로 실행하고 관리자·Discord ID·작업 시각을 계정 감사 로그에 남깁니다. 인증 기록 삭제는 Discord 서버의 기존 역할이나 메시지 삭제 작업이 아닙니다. 운영 데이터 정리는 관리자가 화면에서 선택한 대상에 대해서만 수행하며 기능 추가만으로 기존 기록을 일괄 삭제하지 않습니다.
