# 본인 전용 Discord 인증 안내

시작하기 채널의 공용 버튼은 현재 서버·Discord 계정의 인증 상태를 확인한 뒤 누른 사람에게만 보이는 개인 안내를 엽니다. 미인증 상태에서만 **1 · LMS 인증**으로 코드를 입력합니다. 인증을 완료했다면 **LMS 인증 완료**가 표시되고 자기소개를 이어갈 수 있습니다. 개인 패널은 15분 뒤 만료되고 공용 버튼에서 다시 열 수 있습니다. 계정 정보·인증 결과·후속 안내는 ephemeral 응답이며, 패널은 요청한 사용자와 서버에 연결됩니다.

일회용 코드의 유효기간과 완료된 계정 인증은 별개입니다. 인증 기록은 코드 만료·정리 후에도 유지되며, 자기소개를 나중에 작성해도 재인증하지 않습니다. 인증 상태 조회 실패를 미인증으로 처리하지 않습니다. 자기소개가 저장된 후 역할 반영이 실패하면 저장 완료와 자동 재시도 안내를 표시합니다.

자동 가입 안내는 DM으로 전달합니다. DM을 차단한 사람에게 채널 멘션이나 개인 패널을 공개하는 대체 동작은 없습니다. DM 없이도 시작하기의 공용 버튼으로 인증할 수 있습니다. 전송 상태를 저장해 동기화 때 반복 발송하지 않습니다.

수강생 자기소개 게시물은 기존 자기소개 채널에 공개됩니다. 인증 코드와 계정 확인 패널의 공개 범위와는 별개입니다. 멘토·운영자는 자기소개가 필요 없습니다.
