# 멘토링 활동 기록

예약 없이 진행한 서버 환경 설정 지원 등의 멘토링을 웹에서 기록한다.
이미지 첨부·다운로드, 신규 저장소, Discord 알림은 이번 범위에 포함하지 않는다.

## 사용 방법

1. 멘토링 관리 화면 오른쪽 위의 `+` 버튼을 누른다.
2. 제목, 학습 과정, 대상 팀 또는 참여 학생, 진행일, 시작·종료 시간, 진행 내용을 입력한다.
3. 저장하면 기존 일정 아래의 **멘토링 기록** 목록에서 확인할 수 있다.
4. 목록의 수정 버튼으로 내용을 정정한다. 예약 생성이나 재조율과는 별개 기능이다.

멘토는 로그인한 본인 이름이 자동 입력되며 변경할 수 없다. 관리자는 해당
워크스페이스에 등록된 멘토를 선택한다. 관리자의 기존 `일정 등록` 버튼은 유지한다.
시간은 한국시간이며, 같은 날에 진행을 마친 활동만 입력한다.

## 권한과 데이터 경계

| 역할 | 조회·등록 | 수정 |
| --- | --- | --- |
| 멘토 | 본인 명의 기록, 담당 과정·팀·학생 범위 | 본인 명의 기록만 |
| 워크스페이스 관리자 / 총관리자 | 접근 가능한 워크스페이스의 모든 기록, 멘토 선택 | 해당 워크스페이스 기록 |
| 학생 | UI 미노출, API 403 | API 403 |

- 권한과 소속은 서버에서 검증한다. 멘토 ID를 변조해도 다른 사람으로 등록할 수 없다.
- 보관된 워크스페이스는 조회만 가능하다.
- 관리자가 대신 작성해도 선택된 멘토의 기록이며 그 멘토가 수정할 수 있다.
- 기존 예약·슬롯·후기·Discord 전송 큐는 변경하지 않는다. 기존 예약 건수에는 합산하지 않는다.
- 팀이나 담당 범위가 변경된 뒤에는 현재 범위 밖의 기록 수정을 제한한다. 관리자가 정정할 수 있다.

## 구현 및 실패 처리

- `GET/POST /api/workspaces/:workspaceId/mentoring/activities`
- `PATCH /api/workspaces/:workspaceId/mentoring/activities/:recordId`
- 기존 워크스페이스별 `lms_records`의 `mentoringActivity` 종류로 저장한다.
  스키마 마이그레이션과 신규 테이블은 없다.
- 등록·수정과 감사 로그를 한 트랜잭션으로 처리한다. 감사 로그 저장 실패 시 기록도 롤백한다.
- 생성 요청 UUID로 응답 유실 후 재시도를 중복 처리하지 않는다. 결과가 불확실하면
  입력을 고정한 채 같은 요청을 재전송하거나 닫고 목록을 새로고침하도록 안내한다.
- 수정은 revision으로 충돌을 감지한다. 오래된 화면에서 저장하면 409로 차단한다.
- 기존 전체 DB 백업에 포함된다. 코드만 이전 버전으로 되돌리면 기록은 보존되지만
  이전 UI에서는 보이지 않는다. 다시 배포하면 조회할 수 있다.

## 검증 (2026-10-21)

운영 계정·운영 DB 대신 격리된 로컬 테스트 계정과 DB로 검증했다.

- `npm run lint`, `npm run build` 통과. 빌드는 기존 번들 크기 경고가 남는다.
- `npm test`: 174개 통과.
- PostgreSQL 17.6 `npm run test:postgres`: 24개 통과. 새 기록의 백업·복원 포함.
- Playwright 7개 통과: 신규 입력·수정·네트워크 응답 유실 재시도·역할별 권한과
  기존 멘토링 일정·후기·역할별 탐색 회귀 테스트.
- 기존 승인 예약을 미리 넣고 기록 추가·수정 전후 예약·슬롯·후기·알림 큐가 동일함을 확인한다.
- 데스크톱 1440px, 모바일 390px/360px 모달 캡처와 가로 넘침을 확인한다.

### 추가 UI 정리

- 기존 폰트·녹색 톤·버튼·아이콘 체계를 유지한다.
- 재조율 패널의 누락된 내부 여백, 제목 크기와 섹션 사이의 중복 간격을 수정한다.
- 새로고침 버튼은 44px 클릭 영역, 오른쪽 정렬, 요청 중 비활성화와 상태 표시를 제공한다.
- 일정 변경 도움말, 빈 상태, 오류/재시도 표시를 정리하고 360px에서도 버튼이 겹치지 않게 한다.
- 이 패널은 학생 화면에서도 공유하므로 기존 학생·멘토 일정 제안/수락 흐름을 함께 검증한다.
  새 활동 기록 기능의 학생 접근 차단은 유지한다.
- 추가 UI를 포함한 로컬 브라우저 테스트 9개 통과. 1440/768/390/360px 배치 검증 포함.

```sh
cd lms-web
npm run lint
npm run build
npm test
# 반드시 운영이 아닌 별도 테스트 PostgreSQL을 사용한다.
POSTGRES_TEST_URL=postgresql://... npm run test:postgres
PLAYWRIGHT_DATABASE_URL=postgresql://... npx playwright test \
  tests/mentoring-activities.spec.ts tests/mentoring-layout.spec.ts \
  tests/mentoring-feedback.spec.ts tests/role-workspaces.spec.ts \
  tests/mentoring-coordination.spec.ts tests/mentoring-coordination-layout.spec.ts
```

캡처는 `lms-web/test-results/mentoring-activity-*.png`에 생성된다. 운영 도움말이나
PDF를 수정한 것은 아니며, 운영 배포는 별도 승인 후 진행한다.
