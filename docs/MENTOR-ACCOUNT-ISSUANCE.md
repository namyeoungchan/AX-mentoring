# 멘토 계정 발급과 Discord 인증

워크스페이스의 **구성원 · 초대**에서 멘토 아이디, 이름, 메인 강사/조 담당 멘토 구분과 담당 조를 입력하고 **계정과 초대 링크 만들기**를 누릅니다. 워크스페이스 관리자와 총관리자가 발급할 수 있습니다.

새 멘토는 회원가입하지 않습니다. 안내문에 표시된 초기 비밀번호와 링크를 전달받아 로그인 → 비밀번호 변경 → 초대 수락 → LMS 기본 정보 저장 → Discord 인증 순서로 진행합니다. 초기 비밀번호는 계정마다 자동 생성되며 안내문을 닫으면 다시 표시하지 않습니다. 기존 계정은 **초대 링크만 발급 (기존 계정)**을 사용하고 기존 비밀번호를 유지합니다.

인증된 멘토·운영자는 자기소개 없이 Discord 온보딩 완료 역할을 받습니다. 멘토의 안내 완료 상태는 역할·별명 동기화보다 먼저 저장해 재시도나 봇 재시작 후 자기소개 안내가 다시 발송되지 않도록 합니다. 자기소개 제출 여부를 임의로 변경하지 않으며 수강생의 자기소개 절차는 그대로 적용합니다. 이미 인증한 멘토도 다음 동기화에서 적용됩니다.

검증은 SQLite/PostgreSQL의 계정 발급·권한·담당 조·실패 롤백, 브라우저의 발급→로그인→초대 수락, 봇의 자기소개 생략·완료 역할·동기화 실패 후 재시도·재시작을 포함합니다.
