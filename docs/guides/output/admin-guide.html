02 / 수업 운영

기록하고 저장한 뒤,
필요한 알림을 보내세요.

출결·팀·과제의 저장 결과는 웹에서 확인합니다. Discord 알림은 별도로 전달됩니다.

ATTENDANCE

코드로 출석받고, 예외를 확인하세요

  1. 01회차 시작

    과정 · 날짜 · 차시
    회차 시작

  2. 02코드 발급

    출석 코드 발급
    기본 5분 · 현장 안내

  3. 03등록·예외 확인

    학생 /출석 등록
    수기 수정은 일괄 저장

  4. 04회차 마감

    전체 미처리 0명 확인
    회차 마감

학생 등록은 자동 저장됩니다.

명단은 5초마다 갱신됩니다. 수기 입력 중에는 갱신을 멈추므로 저장·새로고침으로 확인하세요. 코드는 1·3·5·10분 중 선택하며, 코드 종료·만료·회차 마감 후에는 등록할 수 없습니다. 마감 후 정정에는 사유가 필요합니다.

ASSIGNMENTS

과제: 대상 확인 후 배포

과제 만들기팀 / 개인 선택
팀 과제→각 팀의 비공개 채팅
개인 과제→인증된 수강생의 DM
발송 순서

과제 관리›과제 제출 대상·알림›대상·마감 확인›과제 배포

배포 요청 ≠ 발송 완료

대기·발송 완료·실패를 대상별로 확인하세요. 팀 채널 미설정이나 개인 인증 누락은 대기할 수 있습니다.

제출과 마감 알림도 확인

팀은 한 건 이상 제출하면 완료로 집계합니다. 미제출 대상 D-1 안내는 한국시간 오전 9시부터 처리합니다.

03 / 사람·알림·문제 해결

문제가 생겨도
확인할 순서는 같습니다.

누구에게 어떤 권한이 있는지, 저장과 전달 중 어디까지 끝났는지 먼저 확인하세요.

PEOPLE

구성원과 수강생 관리

멘토 초대·담당 조 배정

구성원 · 초대에서 멘토를 초대합니다. 메인 강사는 전체 조, 조 담당 멘토는 선택한 조를 담당합니다.

학생 계정·초기 비밀번호 발급

학생 계정 발급에서 아이디와 과정·조를 지정합니다. 발급된 초기 비밀번호는 한 번만 표시되므로 학생에게 전달하세요.

구성원 제외와 계정 삭제는 다릅니다.

워크스페이스에서 제외해도 개인 계정과 다른 워크스페이스 소속은 남습니다. 워크스페이스 관리자 변경·삭제 및 전체 계정 복구는 총관리자에게 요청하세요.

RECOVERY

이 상태라면 이렇게 하세요

알림이 대기 / 실패예요

Discord 인증·팀 채널·앱 권한을 확인하세요. 확정 실패는 원인을 고친 뒤 알림 재시도를 누릅니다. 결과가 불명확하면 기존 메시지 확인부터 진행하세요.

Discord가 안 되지만 수업은 진행해야 해요

웹이 정상이면 출결을 계속 저장합니다. 웹도 안 되면 사전 CSV나 종이 명단에 기록하고, 복구 후 같은 회차에 가져와 확인·저장하세요.

공지를 직접 전달해야 해요

공지 관리에서 초안·미리보기·발송 상태를 확인합니다. 수동 게시가 필요하면 자동 발송을 먼저 중지하고 기존 메시지와 중복되지 않게 처리하세요.

✓수업 전: 과정·팀 명단과 오늘의 출결 회차 확인

✓수업 후: 미처리 0명, 출결 저장·마감, 알림 실패 확인

문의할 때: 워크스페이스 · 발생 시각 · 진행한 작업 · 오류 문구를 전달하세요.
비밀번호와 인증 코드는 전달하지 마세요.
