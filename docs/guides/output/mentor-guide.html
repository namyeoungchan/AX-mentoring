멘토 활동을 시작하세요.

초대받은 아이디로 계정을 만들거나 로그인한 뒤, 초대 수락을 누릅니다.

시작하는 곳

QR을 스캔하거나 아래 주소를 누르세요.

ax-learningops-web.onrender.com ↗
ONBOARDING

멘토 온보딩

  1. 01

    기본 정보 저장

    활동 이름과 전문 분야를 입력하세요. 활동 이름은 해당 워크스페이스에서 사용합니다.

  2. 02

    Discord 서버 참여

    화면의 Discord 서버 참여를 누릅니다. 초대 링크가 없거나 만료되면 초대 링크 발급 · 재발급을 사용하세요.

  3. 03

    LMS 인증

    웹에서 인증 코드 받기 → 해당 서버에서 /lms인증 코드:발급코드를 실행합니다. 다른 워크스페이스에서는 별도로 인증합니다.

  4. 04

    업무 안내 확인

    과제 생성·예약 승인·멘토링 진행 안내를 순서대로 확인합니다. 안내 확인은 실제 업무 완료 기록과는 다릅니다.

메인 강사전체 조

과정 회차 시작·마감 가능

조 담당 멘토배정받은 조

담당 명단의 출결 입력·정정

멘토는 수강생 자기소개를 작성하지 않습니다.

담당 조가 잘못 보이면 워크스페이스 관리자에게 배정 변경을 요청하세요. 본인이 담당 범위를 바꿀 수는 없습니다.

02 / 수업 진행

명단을 빠르게 확인하고,
수업에 집중하세요.

출결·성적·팀 배정은 본인에게 허용된 과정과 담당 조 범위에서 처리합니다.

출결 화면

멘토 활동 관리›출결 관리

  1. 01회차 확인

    과정 · 날짜 · 차시
    담당 명단 확인

  2. 02예외 표시

    지각 · 결석 · 공결
    해당 행에서 선택

  3. 03나머지 출석

    미처리 출석 또는
    선택 인원 일괄 지정

  4. 04저장 확인

    출결 일괄 저장
    성공 메시지 확인

✓ 출석◷ 지각× 결석◇ 공결— 미처리
메인 강사와 조 담당 멘토의 마감 권한은 다릅니다.

메인 강사는 회차를 시작·마감할 수 있습니다. 조 담당 멘토는 입력을 마친 뒤 마감을 요청하세요. 마감 후 변경에는 새 정정 사유가 필요합니다.

DAILY WORK

함께 사용하는 메뉴

과제 만들기

멘토 온보딩 → 과제 만들기에서 과정·제목·마감일을 입력합니다. 현재 멘토 화면의 생성 과제는 팀 과제이며, 선택한 과정 전체에 공개됩니다.

알림 배포 요청

과제 생성 후 관리자에게 과제 배포를 요청하세요. 개인 과제 생성과 배포 알림 관리는 관리자 화면에서 진행합니다.

수업 현황·성적 관리

수업 현황에서 과정과 과제 현황을 확인합니다. 성적 관리에서는 담당 범위의 평가항목과 점수를 확인·입력합니다.

팀 배정·기존 신청 확인

담당 대상과 소속 팀을 확인하세요. 신규 학생 계정 발급은 관리자에게 요청합니다. 기존 가입 신청은 허용된 범위에서 처리합니다.

03 / 멘토링과 문제 해결

예약부터 피드백까지,
한 흐름으로 이어가세요.

Discord 인증을 완료하고 멘토링을 받을 수 있는 시간을 먼저 등록하세요.

MENTORING

멘토링 운영 흐름

  1. 01

    시간과 예약 슬롯 준비

    Discord에서 /멘토 설정을 실행해 시간대와 예약 가능한 슬롯을 설정합니다.

  2. 02

    수강생 신청 검토

    봇이 보내는 DM에서 신청을 확인하고 승인하거나 사유와 함께 거절합니다. DM 수신이 가능한지 확인하세요.

  3. 03

    확정된 일정에 진행

    확정 시간에 담당 조 음성 채널에서 진행합니다. 조 대화 채널에 피드백과 다음 할 일을 공유하세요.

QUICK HELP

막힌 단계부터 확인하세요

담당 명단이 달라졌거나 저장이 충돌해요

입력 내용을 먼저 보관하고 명단 새로고침 후 최신 배정을 확인하세요. 다른 멘토가 저장한 내용과 대조해 다시 입력합니다.

팀 채널이 보이지 않아요

맞는 워크스페이스·Discord 서버인지 확인하고 인증 완료와 담당 조를 확인하세요. 관리자에게 팀 배정과 동기화 상태 확인을 요청합니다.

비밀번호를 잊었어요

워크스페이스 관리자를 통해 총관리자에게 초기 비밀번호 재발급을 요청하세요. 다시 로그인한 뒤 본인 비밀번호로 변경합니다.

✓수업 전: 담당 조·회차·명단 확인

✓수업 후: 출결 저장, 예약 처리, 피드백 전달 확인

출결 기록은 웹에서 이어갈 수 있습니다.

Discord나 봇만 멈췄다면 웹 출결 입력을 계속하세요. 웹도 사용할 수 없으면 CSV·종이 명단에 기록하고 관리자와 함께 복구합니다.
