첫 참여 체크포인트

  1. 01

    발급받은 계정으로 로그인

    관리자가 전달한 아이디와 초기 비밀번호로 로그인하세요. 과정과 조는 관리자가 미리 배정합니다.

  2. 02

    내 이름 입력 · 비밀번호 변경

    첫 로그인 화면에서 본인 이름을 입력하고 초기 비밀번호와 다른 새 비밀번호를 설정합니다. 설정 완료하고 시작하기를 누르세요.

  3. 03

    Discord 참여 · LMS 인증

    웹의 워크스페이스 참여 현황에서 서버에 참여하고 인증 코드를 받으세요. 시작하기 채널의 1 · LMS 인증에 입력합니다.

  4. 04

    자기소개 작성 · 팀 채널 확인

    본인 계정을 확인한 뒤 2 · 자기소개 작성을 완료합니다. 인증·팀 배정·자기소개가 완료되면 학습 채널이 열립니다.

인증은 워크스페이스마다 따로 진행합니다.

다른 서버에서 인증했더라도 현재 서버에서 새로 인증하세요. 가입 인증 코드·초대 링크는 웹에서 재발급합니다. 채널이 보이지 않으면 위 네 단계를 확인하고, 비밀번호 복구는 관리자에게 요청하세요.

02 / 과제와 멘토링

알림을 확인하고,
제출 완료까지 확인하세요.

과제명과 마감일은 웹의 과제 메뉴 또는 Discord /과제 목록에서 확인합니다.

팀 과제 알림내 팀 채팅에서 확인
개인 과제 알림봇의 개인 DM에서 확인
SUBMIT

과제 제출은 Discord 제출 패널에서

  1. 01과제 선택

    과제 채널의
    과제 제출하기

  2. 02내용 작성

    제출 항목 작성
    필요한 링크 첨부

  3. 03제출 확인

    제출 버튼 클릭
    제출 완료 확인

중복 제출과 팀 대표 제출에 유의하세요.

현재 개인별로 같은 과제에 한 번 제출할 수 있습니다. 팀 과제는 팀원의 제출 한 건 이상이면 완료로 집계하며, LMS 배정 팀으로 제출됩니다. 수정이 필요하면 멘토에게 문의하세요.

BOOKING

멘토링 예약

  1. 01

    예약 가능한 시간 선택

    Discord 멘토링 채널의 예약 패널에서 멘토와 가능한 시간을 선택해 신청합니다.

  2. 02

    신청 상태 확인

    신청만으로 확정되지 않습니다. 멘토 승인 결과를 확인하세요. /mybooking으로 본인 예약 현황을 볼 수 있습니다.

  3. 03

    확정 시간에 참여

    안내된 팀 음성 채널에 참여하세요. 일정 변경이 필요하면 멘토에게 알리고 기존 예약을 확인합니다.

개인 과제 알림을 받으려면 봇의 DM을 수신할 수 있어야 합니다.
알림이 오지 않아도 웹에서 과제와 마감일을 확인하세요.

03 / 입퇴실과 나의 학습

시작·종료 코드로,
강의 출석을 기록하세요.

해당 수업 서버에서 LMS 학생 계정의 Discord 인증을 먼저 완료하세요.

ATTENDANCE

시작 코드는 입실, 종료 코드는 퇴실

  1. 01강의 시작

    패널 입실을 눌러
    시작 코드 입력

  2. 02강의 종료

    패널 퇴실을 눌러
    종료 코드 입력

  3. 03웹에서도 가능

    나의 출결에서
    같은 6자리 코드 입력

두 코드를 등록하면 출석 기록이 완료됩니다.

강사가 안내한 유효시간 내 코드를 입력하세요. 나의 출결에서 강의 예정 시간대와 실제 입퇴실 시각을 확인합니다. 코드 없이 출석할 수 없으며, 재입력은 최초 시각을 유지합니다.

MY LEARNING

웹에서 내 기록 확인

과정 · 팀 · 성적

좌측에서 워크스페이스를 선택하세요. 나의 학습에서 과정·팀, 나의 성적에서 점수를 확인합니다. 모바일은 메뉴 열기를 누르세요.

출결 · 과제 · 마감일

나의 출결에서 회차 마감 후 확정 기록을 봅니다. 과제에서 마감일을 확인하고, 제출은 Discord 패널에서 진행하세요.

출석 등록이 안 돼요

비밀번호나 가입 인증 코드는 공유하지 마세요.
